## Pro 和 T1 的差别，不在配置表上

两条线可以买到的 CPU 核数和内存看起来差不多，真正拉开距离的是路由。

TYO.Pro 的策略是回程三网全部走优质线路：电信和联通回程走 CN2 GIA（CTG GIA），移动回程走 CMI，去程电信、联通同样走 CTG GIA，移动走 CMI。AS9929 和 AS10099 也在联通方向的链路里出现。这套组合的意义在于晚高峰不挤公网节点，公开的路由测试里，国内多数地区延迟落在 60ms 上下，上海方向能看到 31ms 这样的数字。

TYO.T1 走的是普通国际互联：电信和联通双程都走 NTT，部分路由还会绕行美国 Lumen，移动方向走 CMI。它没有针对中国大陆做的优化，也不承诺大陆方向的访问质量。它的优势在别处——流量用完后限速不停机，WEE 档限到 50Mbps 仍然可以继续跑，T1 更适合东南亚业务落地、纯日本本地项目，或者你只是想拿一个日本 IP 而不在乎回国速度。

如果你的用户在国内，T1 不是省钱的选择，而是选错了工具。这一条先说在前面，比后面省多少美元都重要。

## 下单前要确认的几件事

**流量超额的后果不一样。** Pro 是暂停服务，不是限速，流量跑完当天业务就断了；T1 是限速继续跑，WEE 限 50Mbps、TINY 到 MINI 限 100Mbps。这个差别比配置表上任何一行都更影响实际使用。

**IP 更换有规则。** IP 被墙可以申请免费更换，免费额度有周期限制，多个来源提到是 15 天一次；非被墙原因的更换一般收费 5 美元，而且部分特价机型会收紧到 30 天一次。品川这类限量套餐在 IP 更换上限制更严。

**付款方式对国内用户友好。** 支付宝、微信、PayPal、信用卡都可以，不用折腾外币卡。

**先测再买。** 东京 Pro 的公开测试 IP 是 154.12.190.32，T1 是 154.31.112.5。自己 ping 一下、跑个路由追踪，比任何测评文章都准。

**库存是真紧张。** 东京 Pro 的补货通常来自释放出的 IP 资源，补完就没了，官方也说过短期内不会补其他系列。看中了 TINY 想等降价，结果往往是等来缺货。

## 常见问题

**TYO.EB 还能买到吗？**
买不到了，2026 年 6 月 15 日已正式下线。持有该服务的用户按官方补偿方案处理，可以申请 Pro 循环折扣或年付特别产品名额。

**东京 Pro 和香港 Pro 怎么选？**
香港延迟更低，通常 20 到 40ms，价格也更高，起步约 $259.9/年。东京的 60ms 上下属于「比香港慢一点、比美西快一截」的位置，价格便宜不少。对延迟极度敏感选香港，其余情况东京更合适。

**年付比月付划算多少？**
T1 的年付折扣是明码标价的（TINY $76.9/年、STARTER $154.8/年、MINI $262.8/年，都比月付乘 12 便宜）；Pro 的年付优惠主要靠优惠码实现，没有码的情况下按 12 个月算，差价不明显。

**第一次买 DMIT，需要多大配置？**
先按用途定流量，再按流量定档位。跑一个 WordPress 站加几个容器，Pro.MINI（2 核 2GB、2TB 流量）够用；只做代理或跳板，TINY 就是合理起点。上来买 LARGE 或 GIANT 之前，最好先算清楚月流量到底会用多少。

东京这两条线其实不难选：需要大陆方向快，只有 Pro 一个答案，剩下的只是买哪档；不需要大陆方向快，T1 用不到一半的钱能拿到多得多的流量和算力。难的是库存和时机，Pro 的补货窗口经常只有几天。
